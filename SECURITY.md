# Security Policy / 安全策略

Only the latest GitHub Release is supported with security fixes. Please confirm the issue against that version before reporting it.

请仅针对最新 GitHub Release 报告安全问题，并先确认问题可在该版本复现。

Do not publish active exploit details, private content, credentials, session data, or personal information in a public issue. Contact the maintainer through the private contact method available on the [Nuancunv GitHub profile](https://github.com/Nuancunv). Include the affected version, Android version, reproducible steps, impact, and the smallest safe supporting material.

请勿在公开 Issue 中发布可直接利用的细节、私人内容、凭据、会话数据或个人信息。请通过 [Nuancunv GitHub 主页](https://github.com/Nuancunv)提供的私密联系方式联系维护者，并说明受影响版本、Android 版本、复现步骤、影响和必要的最小材料。

This project provides no security bounty and cannot guarantee a response time. Reports made in good faith will be assessed before public disclosure.

本项目目前不提供漏洞赏金，也不承诺固定响应时间；善意报告会在公开披露前进行评估。
