# v1.3.0 定档与安装说明

发布日期：2026-10-18。正式签名安装包及校验文件见 [v1.3.0 Release](https://github.com/Nuancunv/JMComic_downloader_Mobile/releases/tag/v1.3.0)。

## 这次更新

- **搜索优化**：查询整理、繁简兼容、分级相关性排序、结果去重、稳定分页、匹配高亮与书名建议。
- **UI 重构**：重做书库、搜索、任务、详情和阅读界面，统一暖色与玻璃工具栏，支持浅深主题，压缩页头并优化过渡和状态保留。
- **下载优化**：图片并发、动态队列、共享网络预算、阅读优先、限流处理与线路回退；完成章节可以提前阅读。
- **PDF 与恢复**：线性页树校验、有界图片流暂存、直接嵌入 JPEG、可取消保存/校验、失败保留旧 PDF；完整本地章节可不经 API 重建 PDF。
- **接口兼容**：UTF-8 BOM、2.1.7 协议标识及异常响应切线，错误章节模板不再误判成功。

完整说明见 [版本记录](RELEASE_NOTES.md)。

## 覆盖 v1.2.0

正式 v1.2.0 的包名相同，versionCode 为 5，本包沿用其原正式证书，满足覆盖更新所需的包名、签名和版本号条件。安装时选择“更新”，**不要先卸载旧正式版**。

数据库迁移保留原书库、PDF 路径和阅读位置。安装后核对自己的书库、归档、阅读进度及导出。

之前的搜索/UI 测试包使用 `com.nuancun.jmcomic.mobile.searchtest` 和另一张证书，与正式版是两个应用。本次正式包不会覆盖它，也不会自动合并测试版书库。
