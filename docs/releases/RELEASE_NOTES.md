# 版本记录

[English](RELEASE_NOTES.en.md)

## v1.3.0 — 搜索、界面、下载都重新收拾了一遍

这次把几轮搜索、UI、下载和 PDF 改进合在一起，最终版本定为 **v1.3.0**。

### 搜索更顺手

- 重新做了查询整理和相关性排序，支持编号、链接、书名、作者、标签和章节名；兼容全角、空格、标点及繁简写法，准确书名优先。
- 在线结果会合并重复作品，保留作者和标签；加载更多时尽量保持已有顺序。换搜索词会取消旧请求，部分线路失败时保留可用结果。
- 增加匹配理由、关键词高亮和本地书名建议；修复大列表反复扫描最新任务记录的问题。

### 界面重构

- 重做书库、搜索、任务、作品详情和阅读界面，统一暖色、纸面和玻璃工具栏；支持跟随系统、浅色和深色。
- 压缩页头空白，增加页面过渡，保留列表位置；任务分为进行中和已结束，搜索卡片可直接查看下载进度。
- 滚动和转场期间暂停部分动态特效；PDF 打开和图片处理移出主线程，减少不必要的绘制和重复工作。

### 下载与阅读

- 图片并发下载、动态领取任务，多本作品共享网络预算；正在阅读的作品优先，失败或限流时调整线路与并发。
- 章节信息有限预取，不再等全书清单都拿到才下首章。完成的章节可以先看，后续章节下载好后继续加入阅读。
- 重试复用校验通过的本地图片；取消、删除和写文件互相配合，避免取消后还在后台落盘。
- 书签增加章节定位，兼容旧页码；数据库显式从 schema 3 升到 4，保留旧书库、PDF 路径和阅读位置。

### PDF 与接口稳定性

- PDF 页树校验改成顺序遍历，避免大书反复扫描；压缩图片流采用有限内存加磁盘暂存，减少内存压力。
- 直接嵌入已处理的 JPEG，保留章节目录。保存和校验支持取消；失败清理半成品，发布失败不再主动删除旧 PDF。
- 完整章节通过本地校验后可直接重建 PDF，不用重新请求作品和章节接口；这类重试可断网启动。
- 同步上游 UTF-8 BOM 兼容和 2.1.7 协议标识，补齐业务错误、坏密文及错误模板的线路回退。

### 覆盖升级与验证

正式包使用 `com.nuancun.jmcomic.mobile`，沿用 **v1.2.0 的原正式证书**；内部版本号由 5 升为 16，作为直接覆盖更新包准备，无需卸载旧正式版。之前带 `.searchtest` 的独立测试版属于另一个应用，数据不会自动合并。


## v1.2.0 — 首个公开正式签名版本

JMComic Downloader Mobile v1.2.0 是首个公开正式签名版本，面向 Android 8.0（API 26）及以上手机。

### 功能

- 手机本地完成在线检索、图片下载和重排、整本 PDF 生成与阅读。
- 关键词搜索结果按标题、ID、作者和标签相关性排序。
- 搜索结果使用圆形按钮实时显示下载与 PDF 生成进度。
- 本地书库支持检索、左滑归档、左滑删除及隐藏归档入口。
- 任务页统一展示下载和 PDF 导出，支持删除历史而不删除作品。
- 阅读器支持左右分页、上下分页、连续滚动、点击隐藏 UI、窗口亮度、暖色护眼和多种背景。
- Android 返回键与返回手势可关闭弹层并逐级返回。

### 安装提醒

本版本使用新的正式签名。旧测试版如果使用不同签名，无法直接覆盖安装。请先导出需要保留的 PDF，再卸载旧测试版并安装本版本；卸载会清除尚未导出的应用内书库数据。以后使用相同正式签名发布的版本可以覆盖升级。
