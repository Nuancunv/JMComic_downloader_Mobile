# JMComic Mobile 使用手册

[English](UserManual.en.md)

适用版本：正式 v1.3.0（versionCode 16），平台 Android 8.0（API 26）及以上。桌面名称为“JMComic 本地书库”。最新改动与发布状态见 [版本记录](../releases/RELEASE_NOTES.md)。

## 1. 安装与升级

正式安装包为 `JMComic_downloader_Mobile-v1.3.0.apk`，使用 `com.nuancun.jmcomic.mobile` 和 v1.2.0 的原正式签名，用于覆盖升级并保留原正式版书库、任务、PDF 与阅读设置。之前的独立搜索/UI 测试版包名带 `.searchtest`，两边数据不会自动合并。校验值与说明见 [正式版交付说明](../releases/v1.3.0.md)。

1. 将 APK 保存到手机，通过系统“文件”应用打开。
2. 如 Android 提示，临时允许当前文件应用安装 APK，然后选择更新，保留已有正式 v1.2.0 应用，无需卸载。
3. 安装后打开“JMComic 本地书库”，核对原书库、任务、PDF、归档与阅读位置。
4. 安装完成后可关闭文件应用的“允许安装未知应用”权限。

数据库从 Room schema 3 显式迁移到 4，保留原书库、PDF 路径与阅读位置。升级后请核对自己的数据。

安装后，检索、下载调度、图片处理、PDF 生成、书库管理和阅读全部由手机完成，不需要电脑、自建服务器或 NAS。在线检索及新下载需要互联网；已生成的 PDF、目录、本地检索和阅读可离线使用。

## 2. 页面入口

底部有三个入口：

| 页面 | 用途 |
| --- | --- |
| 书库 | 查看、检索、归档、删除本地作品，进入章节目录和阅读器 |
| 搜索 | 输入作品 ID、链接或关键词，查看按相关性排列的在线结果并下载 |
| 任务 | 查看下载与 PDF 导出状态、打开导出详情、取消任务和清理历史记录 |

### 外观设置

点主页面顶栏的外观图标，在“跟随系统 / 浅色 / 深色”中选择，选择立即生效并保存。默认跟随系统。阅读器的背景、暖色和亮度继续独立设置；全局主题不会改变 PDF 图片的原始颜色。导航与阅读工具栏在 Android 12 及以上使用局部磨砂，较低版本使用暖色稳定表面。阅读设置在玻璃外壳内保留暖纸衬底，避免 PDF 页面的明暗影响控件可读性。

## 3. 搜索与下载

1. 打开“搜索”。
2. 输入纯数字 ID、`JM123456`、支持的 `/album/123456` 或 `/photo/123456` 链接，或者关键词。
3. 点输入框右侧“搜索”，或按手机键盘的搜索键；输入内容可用清空按钮移除。
4. 输入会统一整理全角、大小写、空白与标点，并兼容繁简字符。首批结果优先显示 ID、精确标题、等价标题、标题短语、全部标题关键词及近似书名，作者和标签匹配作为补充；卡片显示命中理由与高亮。有现有书库时，输入可出现最多五个本地书名建议，点击即可提交搜索。
5. 标题候选不足时，首批会补充少量查询变体并按条件预取第二页。点列表底部“加载更多”时，新增结果按作品 ID 去重，已有卡片保持顺序，新作品追加到后面；失败时可重试，切换查询会取消旧搜索。
6. 核对作品标题、作者和标签后点“下载”。按钮会立即变成赤陶色圆环：深色圆周表示已完成比例，浅色表示剩余比例；目录总数未知时显示等待动画，生成 PDF 时环内显示“PDF”，完成后显示勾。完成状态的勾可打开本地作品详情。

手机会读取章节、逐张下载并处理图片，最后生成包含全部章节的一个 PDF。应用同时保留处理后的图片与 PDF，请预留足够空间。离开应用或熄屏后，Android 通常会继续前台下载；厂商省电策略、强制停止、重启或存储不足仍可能中断任务。

下载失败或取消后，已完成的有效图片会保留。进入作品详情点“继续下载”，应用会验证已有页面、补齐缺失内容并重新生成 PDF。

## 4. 管理书库

### 检索

在“书库”顶部输入文字，可按标题、作者、标签、JM ID 或章节名称检索。此检索只读手机本地 Room 数据库，不需要联网；普通书库与归档书库分别检索，归档作品不会混回主列表。

本地检索共用查询整理和繁简字符兼容，支持多个关键词，按相关性排列，同等级再比较更新时间。四字及以上查询支持保守的近似书名匹配；一至三字查询以及包含 `%`、`_` 的查询按字面匹配。结果会显示命中字段或章节并高亮原文。

### 归档

1. 在作品卡片上向左滑，露出相互分隔、四角圆润的浅赤陶色“归档”和浅红色“删除”。
2. 点“归档”，作品会离开普通书库，但图片、PDF、章节目录和阅读进度都会保留。
3. 回到书库列表顶部并继续向下拉，松手后会显示隐藏的“已归档图书”入口；加载图标会自动淡出，点入口进入归档页。
4. 归档页中的作品同样可以打开、阅读和导出。向左滑后点浅赤陶色“取消归档”，作品会回到普通书库。

归档入口平时隐藏；向上滚动或重新进入书库后需要再次在顶部下拉显示。如果没有归档作品，入口不会显示。

### 删除作品

1. 在普通书库或归档页中，将作品卡片向左滑。
2. 点浅红色“删除”，阅读确认框后再次点“删除”。
3. 应用会先阻止该作品继续写入并取消关联下载，再删除应用私有目录中的图片、PDF、章节目录和阅读进度。

删除作品不会删除先前通过系统文件选择器导出的 PDF。操作不可撤销，因此需要保留的作品应先导出。若文件清理失败，应用会保留可重试状态并显示错误，不会把未清理完整的作品报告为成功。

## 5. 管理任务记录

“任务”页按“进行中”和“已结束”分组，组内按更新时间展示下载任务和 PDF 导出任务。下载任务显示等待、读取目录、下载图片、生成 PDF、完成、失败和已取消等状态；导出任务使用文件图标，并按已写入字节显示进度。

- 运行中的任务点卡片右侧取消图标，或点系统通知中的“取消”。任务终止后才能清理记录。
- 对“已完成”“失败”或“已取消”的任务卡片向左滑，点“删除记录”，再确认。
- 删除任务记录只移除任务列表中的这一条历史信息。作品、图片、PDF、目录、归档状态和阅读进度都会保留。
- 点 PDF 导出任务可打开置顶详情层。摘要显示原作品名、实际保存名、保存位置、状态和时间；点“详情”后可查看作者、作品信息和真实文档 URI，长内容在详情层内滚动。点右上角关闭、压暗背景或手机返回键均可关闭。

删除某部作品时，对应下载历史也会保留，之后可在任务页单独清理。

## 6. 章节目录与阅读器

1. 在书库或归档页点作品卡片。
2. 作品详情页列出章节及其 PDF 起始页。点章节可直接跳到该章；点“阅读”从最近位置继续。
3. 阅读器底部左右按钮可前后移动，拖动页码滑块可快速跳页。
4. 点右上角齿轮打开阅读设置。
5. 单击漫画画面可收起或展开顶部栏、底部页码栏和系统状态栏；滑动翻页或连续滚动不会改变当前显隐状态。退出阅读再进入时，工具栏默认显示。

阅读设置包括：

| 设置 | 可选项 | 作用范围 |
| --- | --- | --- |
| 翻页模式 | 左右分页、上下分页、连续滚动 | 当前及以后阅读，切换时保留当前 PDF 页 |
| 亮度 | 跟随系统，或约 5%–100% | 只覆盖阅读窗口；退出阅读后恢复原窗口值，不修改系统亮度设置 |
| 护眼暖色 | 关闭、轻暖、适中、较暖 | 只给阅读内容叠加暖色，不改 PDF 和图片文件 |
| 背景颜色 | 象牙、暖纸、米白、鼠尾草、亚麻、暖砂、墨纸 | 阅读空白、页间区域及工具栏；墨纸时控件自动使用浅色 |

左右分页时向左滑进入下一页、向右滑返回上一页；上下分页时向上滑进入下一页、向下滑返回上一页；连续滚动按页面顺序纵向浏览。翻页停止或连续滚动短暂停顿后，页码与连续模式的页内偏移会自动保存。工具栏隐藏时画面会使用释放出的空间，分页仍按比例完整显示。阅读偏好保存在手机本地，下次打开继续使用。

PDF 页面本身是图片，因此无法对画面中的文字做全文搜索。生成的 PDF 包含标准章节书签，导出后可在支持 PDF outline 的第三方阅读器中使用同一目录。

## 7. 导出 PDF

1. 进入已完成作品的详情页，点“导出 PDF”。
2. 在 Android 系统文件选择器中选择“下载”、文档目录、SD 卡或你信任的存储位置。
3. 修改或保留默认文件名，点“保存”。应用会把导出加入“任务”页并在后台写入；离开作品页不影响导出。任务显示“已完成”且目标文件可打开后，导出文件独立于应用存在。

应用不申请“管理所有文件”权限，只能写入你在系统选择器中明确选择的位置。卸载应用或在系统设置中清除应用数据，会删除整个应用内书库；已导出的 PDF 不受影响。

Android 文件选择器提供的是文档地址，不一定能转换成传统绝对路径。详情会优先显示“内部存储／Download／文件.pdf”等可读位置；无法可靠取得目录时显示存储提供方、文件名和真实 `content://` 文档地址，不会猜测路径。

## 8. 手机返回操作

手机三键导航的返回键与全面屏边缘返回手势都按界面层级工作：先关闭删除确认框、阅读设置或导出详情，再收起已展开的左滑按钮；阅读器返回作品详情，作品详情返回原书库或归档页，归档页返回普通书库，“添加”与“任务”返回书库。普通书库没有浮层时，返回由 Android 正常退出到上一应用或桌面。系统文件选择器和键盘由系统优先关闭。

## 9. 常见问题

### 在线搜索或所有线路失败
检查网络、VPN、私人 DNS 或防火墙。来源接口和域名可能变化；应用只连接代码中已审查的 HTTPS 允许列表，不能在界面中添加任意主机。

### 后台下载停止
重新打开“任务”页。失败或取消的作品可在详情页继续下载。部分手机需要在系统电池设置中允许本应用后台运行；被用户“强制停止”后，必须重新打开应用。

### 没有下载通知
在“系统设置 → 应用 → JMComic 本地书库 → 通知”中允许通知。Android 12 及以下通常不会单独询问。

### 阅读或导出按钮不可用
只有图片下载完成，且 PDF 页数与章节目录校验通过后，按钮才可用。先对失败任务执行“继续下载”。

### 书库找不到归档作品
清空普通书库的检索文字，回到列表顶部继续向下拉，看到“已归档图书”后松手并点入。

### 删除任务后作品仍在
这是预期行为。“删除记录”只整理任务历史；要删除作品及文件，请在书库或归档页左滑作品并选择“删除”。

### 删除导出任务后 PDF 仍在
这是预期行为。任务页只保存导出历史；要删除已经保存到 Download、SD 卡或其他目录的 PDF，请使用手机系统“文件”应用。

### 手机空间不足
先导出要保留的 PDF，再在书库中逐部删除不需要的作品。不要使用“删除任务记录”来释放文件空间，因为它不会清理漫画文件。

## 10. 数据和隐私

应用没有账号登录、云同步、统计上报或远程 PDF 转换。数据库、下载图片、生成的 PDF、归档状态和阅读偏好默认存放在手机应用私有空间。网络请求只在搜索、读取目录和下载图片时发往来源 API 与图片 CDN。

请只下载和保存你有权访问且符合所在地法律和来源服务条款的内容。上游程序的 MIT 许可不授予来源内容的复制或传播权。
